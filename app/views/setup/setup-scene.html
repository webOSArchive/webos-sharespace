Share Space - Setup

Server Required

Share Space requires a server to store and retrieve your shared content.

The community-hosted server is shutting down. To use Share Space, you will need to connect to a server — either one you run yourself, or one hosted by someone you trust.

Running your own server on a Raspberry Pi is easier than it sounds. Visit github.com/webosarchive/sharing-service for step-by-step instructions.

Once your server is running, tap Configure Server below and enter the server address under Server Settings.
